## Known and accepted

- **Old-client strip.** If any device still on v1.15.3 writes to the shared room, foreign
  expenses lose their currency and read as shekels. Closed by upgrading every device, not
  by code — there is no guard, because an old client does not run the new check.
- **Rollover** is untouched: budgets and the fund pot are always ILS, so there is nothing
  to convert.
- **Refunds** are not representable — amounts clamp to non-negative.
- **A day filter cannot fix history.** Paris's 14 undated expenses stay undated; the date
  default only helps from now on.
